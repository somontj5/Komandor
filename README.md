# Командор v2.0 — Claude Code для Android (Мобильный ИИ-агент и среда разработки)

**Командор (Claude Code Mobile)** — это полноценный автономный ИИ-агент и мобильная среда разработки в стиле **Claude Code CLI** для телефона Android. Вы ставите задачу обычным языком или через слэш-команды, а агент:
1. Пишет, читает, ищет и патчит код в локальном воркспейсе с отображением **Unified Diff** и запуском в **Bash**-песочнице.
2. Управляет разрешёнными приложениями на экране телефона (Claude, Gemini, Genspark, Termux, браузер и др.) через **AccessibilityService (`ScreenDriver`)**.
3. Соблюдает жёсткие аппаратные правила безопасности (**`Blocklist`**): неотключаемый запрет WhatsApp (`com.whatsapp`, `com.whatsapp.w4b`), авто-стоп при появлении капчи (Cloudflare / reCAPTCHA) и защита от ввода СМС-кодов / банковских карт.

## Что реализовано в версии 2.0 (Полный стек M0 → M4)

### 1. Арсенал из 10 инструментов Claude Code (`ClaudeCodeToolset.kt`)
- **`Bash`** — выполнение shell-команд и скриптов внутри локального каталога `/files/workspace` с таймаутами и защитным фильтром команд.
- **`Read`** — чтение файлов проекта с нумерацией строк (`cat -n` формат) и поддержкой смещений (`offset`, `limit`).
- **`Write`** — создание и перезапись файлов с автоматической генерацией цветового **Unified Diff**.
- **`Edit`** — точечный патч файлов (`old_string` → `new_string`, `replace_all`) с предпросмотром diff.
- **`Glob`** — быстрый поиск файлов в рабочем каталоге по шаблону.
- **`Grep`** — поиск по регулярным выражениям по всем файлам проекта с указанием строки.
- **`TodoWrite`** — структурированный менеджер задач сессии (`pending`, `in_progress`, `completed`).
- **`ScreenInspect`** — снятие и сериализация дерева элементов активного окна Android (`IndexedUiNode` с индексами `[1]`, `[2]`, координатами `@(x,y)`, классами, `viewId` и флагами `CLICK`, `EDIT`, `SCROLL`).
- **`ScreenAction`** — выполнение действий на экране:
  - `click_index` — клик по номеру узла `[N]` из дерева экрана (или жест нажатия по его координатам)
  - `click_text` — поиск и нажатие элемента по тексту, `contentDescription` или `viewId`
  - `click_xy` — точечный жест нажатия (`GestureDescription`) по координатам `(x, y)`
  - `type` — фокусировка и ввод текста (`ACTION_SET_TEXT`) в поле `EditText`
  - `scroll` — прокрутка списков и свайп-жесты (`up`, `down`, `left`, `right`)
  - `back`, `home`, `recents`, `notifications` — системные глобальные действия Android
- **`AppLaunch`** — запуск разрешённых приложений по имени или пакету с проверкой через `Blocklist`.

### 2. Автономное ядро ReAct и мульти-провайдерный LLM-роутер (`ClaudeCodeEngine.kt`)
- **Многошаговый цикл ReAct (`Think → Tool Call → Observe → Repeat`)**: агент разбивает задачу на шаги, вызывает инструменты, анализирует вывод и формирует итоговый ответ.
- **Поддержка облачных моделей**:
  - **Anthropic Claude API** (`claude-sonnet-4-5`, `claude-3-7-sonnet`)
  - **OpenAI-совместимые API** (`gpt-5`, `deepseek-chat`, OpenRouter, локальный Ollama / LM Studio)
- **Автономный локальный тактический планировщик**: работает мгновенно и **100% офлайн без API-ключа**, понимает команды на русском и английском языках, автоматически читает `CLAUDE.md`, генерирует скрипты и управляет экраном.

### 3. Мобильный интерфейс из 4 вкладок в стиле Claude Code (`MainActivity.kt`)
1. **Терминал**: карточки шагов (`✻ THINK`, `⚙ TOOL`, `✓ RESULT`, `✻ CLAUDE CODE`, `✖ ERROR`), встроенный просмотрщик цветных `diff` (`+` зелёные / `-` красные строки), панель быстрых чипов (`/status`, `/ls`, `/read CLAUDE.md`, `/todo`, `/screen`, `тест`).
2. **Файлы (Workspace IDE)**: файловый менеджер локального воркспейса, встроенный редактор кода, создание новых файлов, сохранение с `Diff` и запуск одной кнопкой в `Bash`.
3. **Экран UI (Live Inspector)**: живой инспектор узлов `AccessibilityService` — нажимайте на любой найденный элемент `[1]`, `[2]` прямо из списка, чтобы выполнить клик, вводите текст или тестируйте скролл.
4. **Настройки**: выбор провайдера LLM, `Base URL`, модели, API-ключа и просмотр активных правил защиты `Blocklist`.

## Слэш-команды терминала
- `/help` — список всех команд и примеры запросов
- `/status` (или `/doctor`) — полная диагностика агента, воркспейса, `ScreenDriver` и `Blocklist`
- `/ls` — список файлов в рабочем каталоге
- `/read <путь>` — прочитать файл с номерами строк (например, `/read CLAUDE.md`)
- `/bash <команда>` — выполнить shell-команду в песочнице
- `/grep <шаблон>` — найти текст или регулярное выражение в файлах
- `/todo` — показать текущий план задач сессии
- `/screen` — снять дерево элементов текущего экрана телефона
- `/open <приложение>` — запустить разрешённое приложение (`claude`, `gemini`, `genspark`, `termux`)
- `/clear` — очистить ленту терминала
- `тест` — классический тест этапа M1 (нажатие первой кликабельной кнопки на экране)
