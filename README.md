# Командор — ИИ-агент для Android (этап M0 + каркас M1)

Приложение-терминал: вы пишете задачу обычным языком, агент управляет
разрешёнными приложениями на телефоне (Claude, Gemini, Genspark и другие)
через AccessibilityService.

## Что уже есть (M0 + M1)
- Сборка APK через GitHub Actions — без ПК и без Gradle Wrapper.
- Terminal UI: тёмный чат, кнопка Старт/Стоп агента.
- AgentService: foreground-сервис с уведомлением.
- ScreenDriver: каркас AccessibilityService + тестовая команда «тест».
- Blocklist: жёсткий запрет WhatsApp (не отключается).

## Тест после установки (критерий M0)
1. Установите APK и откройте приложение — должен открыться тёмный терминал.
2. Нажмите «Старт» — в шторке появится уведомление «Командор: агент активен».

## Тест M1 (после M0)
1. Настройки → Специальные возможности → «Командор — драйвер экрана» → Вкл.
   (Android 13+: сначала «Разрешить ограниченные настройки» — см. инструкцию).
2. Откройте любое приложение с кнопкой (например, Калькулятор), вернитесь
   в Командор, введите слово «тест» и отправьте — агент нажмёт первую
   доступную кнопку на экране.

## Безопасность
- Агент не обходит капчи и защиту от ботов: при их появлении он
  останавливается и зовёт человека.
- Пароли, платёжные данные и коды из СМС без явной команды не вводятся.
- WhatsApp запрещён на уровне кода.
